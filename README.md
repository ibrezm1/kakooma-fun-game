# Kakooma Math Quest ⚡

An engaging, fast-paced mental math puzzle game built with modern web technologies. Train your brain with addition and multiplication challenges across multiple puzzle sizes and difficulty levels.

## 🎮 Features

- **Multiple Game Modes**: Addition and Multiplication quest modes.
- **Dynamic Board Sizes**: 5-number, 6-number, 7-number, 8-number, and 9-number boards.
- **Difficulty Settings**: Easy, Medium, Hard, and Insane difficulties.
- **Multi-board Challenges**: Solve single boards or 4-board / 5-board / 9-board multi-challenges with grand finale boards!
- **Interactive Audio & Visuals**: Synthesized sound effects, animations, confetti celebrations, and customizable visual themes.
- **Personal Best Tracker**: Accurate millisecond timer and persistent high scores stored locally.
